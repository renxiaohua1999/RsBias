# RsBias

Code and derived data for evaluating global soil respiration estimates and the
effect of spatial sampling bias.

`RsBias.Rmd` compares data-driven and process-based model estimates, evaluates
the environmental representativeness of soil-respiration observation sites, and
produces bias-corrected global and biome-level estimates.

## Contents

- `RsBias.Rmd` — analysis workflow and figure generation
- `result/` — generated figures and derived data products
- `LICENSE` — license for the code

The workflow can be rendered with R Markdown. Generated figures are written to
`result/`, and the derived data products are stored in `result/zenodo/`.

The generated data and supplementary materials are archived at Zenodo:
[10.5281/zenodo.23333448](https://doi.org/10.5281/zenodo.23333448).
